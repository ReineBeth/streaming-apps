# Tâches : session de sélection partagée

- [ ] Créer le schéma Supabase et les politiques d’accès des sessions.
- [ ] Créer une session avec les filtres et dix titres stables.
- [ ] Générer et partager le lien d’invitation.
- [ ] Rejoindre une session avec un compte ou un nom temporaire.
- [ ] Enregistrer les votes des deux participants.
- [ ] Afficher les titres communs une fois les deux votes terminés.
- [ ] Ajouter les contrôles accessibles et l’état de session complète.
- [ ] Tester les permissions, l’expiration et le rechargement.
