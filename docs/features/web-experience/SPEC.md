# Spec: web-experience

## Objective

Deliver a responsive dark interface with semantic, accessible routes for Home, Explore, Watchlist, History and Settings.

## Acceptance Criteria

- Shared components include equivalents of `MediaCard`, `MediaGrid`, `StreamingBadge`, `RatingStars`, `StatusSelector`, `SearchBar`, `FilterBar` and `Navbar`.
- Explore supports search, movie/TV filtering, service filtering and genre filtering.
- Detail pages show title metadata, artwork, synopsis, genres, duration or season count, TMDB rating and Canadian providers.
- Home includes continue watching, watchlist, popular movies and popular series sections when data is available.
- Each data-driven route has loading, error and empty states and works on mobile and desktop.
